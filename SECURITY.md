# Security policy

## Reporting a vulnerability

Email **security@shoutory.com** with a description, the affected version and steps to reproduce. Please do not open a
public issue, pull request or discussion for a suspected vulnerability.

We read every report, tell you whether we can reproduce it, and keep you informed until a fix ships. We credit
reporters in the release notes unless they ask us not to.

## Scope

In scope: the code in this repository and the container image built from it, including authentication, tenant
isolation, secret handling and the publishing ledger.

Out of scope: findings that need a modified build, physical access to the host, or a social network's own platform.

## Supported versions

Security fixes go to the latest stable release.

## Safe harbour

Good-faith research that avoids other people's data, stays within your own test accounts and gives us time to fix the
issue before disclosure will not be pursued.
